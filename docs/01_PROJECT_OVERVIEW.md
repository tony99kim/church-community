# ChurchHub - 프로젝트 개요

> 2026-10-07 기준 코드와 맞춰 갱신함.

## 프로젝트명
**ChurchHub** (지역 청년 교회 커뮤니티 플랫폼)

## 목적
지역 청년과 여러 교회를 잇는 온라인 공간
- 커뮤니티 게시판, 행사·지역 섬김 안내와 참여 신청
- 교회 소개, 교회 공간·물품 대여
- 신앙 Q&A, 기도제목, 목회자와의 1:1 메시지
- 새가족 웰컴 키트 신청

## 사용자 역할 (`UserRole`)

| 역할 | 표시명 | 할 수 있는 일 |
|------|--------|---------------|
| 비회원 | - | 게시글·댓글·카테고리·행사·교회·공간·물품·공개 신앙 Q&A/기도제목 조회 |
| `USER` | 일반회원 | 글/댓글 작성, 좋아요, 신고, 행사 신청, 공간·물품 대여 신청, 질문·기도제목 작성, DM, 웰컴 키트 신청 |
| `CHURCH_MANAGER` | 교회관리자 | 관리자 화면(`@AdminOnly`). 행사·공간·물품·대여 관리는 **자기 소속 교회 것만**. 신앙 Q&A 관리는 불가 |
| `PASTOR` | 목사 | 관리자 화면 전체 + 신앙 Q&A 답변·기도제목 관리(`@FaithMinistry`). 교회 정보는 자기 교회만 수정 |
| `EVANGELIST` | 전도사 | `PASTOR`와 같음 |
| `SUPER_ADMIN` | 최고관리자 | 전부 + 회원 삭제(익명화)·역할 변경·교회 생성/삭제(`@SuperAdminOnly`) |

- 관리자 역할 판정: 백엔드 `UserRole.isAdmin()`(USER 제외 전부) / `isFaithMinistry()`(PASTOR·EVANGELIST·SUPER_ADMIN), 프론트 `src/lib/roles.ts`가 같은 범위를 씀
- `SUPER_ADMIN`이 아닌 관리자 역할을 부여할 때는 소속 교회가 반드시 지정됨 (`AdminService.updateUserRole`)

## 구현된 기능 (도메인별)

#### 사용자 사이트
- **인증 (auth)** - 이메일 회원가입/로그인, 로그아웃, 토큰 재발급(HttpOnly 쿠키), 이메일·닉네임 중복 확인, **Google·Kakao 소셜 로그인**(일회용 코드 교환 방식)
- **회원 (user)** - 내 정보 조회/수정, 비밀번호 변경(소셜 계정 제외), 회원 탈퇴(개인정보 익명화), 회원별 게시글, 닉네임 검색, 목사·전도사 목록
- **게시판 (board / category)** - 계층형 카테고리(상위-하위), 게시글 CRUD(TipTap 리치 에디터, 이미지), 키워드·카테고리 검색, 페이지네이션, 좋아요 토글, 조회수(사용자/IP당 24시간 1회), 공지 카테고리는 관리자만 작성
- **댓글 (comment)** - 댓글/대댓글 CRUD, 작성자·관리자 삭제
- **행사 (event)** - 카테고리(동네 모임·신앙 모임·섬김·교회 행사·웰컴 테이블)별 목록, 상세, 참여 신청/취소(정원 체크). `/events`와 `/service`(지역 섬김) 화면
- **교회 (church)** - 교회 목록/상세(예배 시간, 청년부 여부, 연락처, 웹사이트, 인스타그램, 이미지)
- **공간 대여 (space)** - 공간 목록/상세, 날짜별 예약 가능 시간 슬롯, 대여 신청/취소, 관리자 차단 시간(반복 요일 또는 특정 날짜)과 겹치는 신청 거부, 중복 예약 방지(비관적 락)
- **물품 대여 (item)** - 물품 목록, 재고 확인 후 대여 신청(약관 동의 필수)/취소, 대여 건별 신청자-관리자 채팅
- **신앙 (faith)** - 신앙 질문(익명·공개 여부 선택), 목회자 답변, 질문별 비공개 1:1 메시지, 기도제목 작성·"함께 기도" 카운트
- **DM (dm)** - 회원 간 1:1 대화(신앙 질문에 연결 가능), 미읽음 수
- **알림 (notification)** - 댓글·대댓글·좋아요, 공간/물품 대여 승인·거절 알림, 미읽음 수(헤더가 60초마다 조회)
- **신고 (report)** - 게시글/댓글/회원 신고
- **웰컴 키트 (welcome)** - 1인 1회 신청, 내 신청 내역·관리자 메시지 확인
- **업로드 (upload)** - 이미지 업로드(Supabase Storage)
- **SEO** - 게시글 상세 `generateMetadata`로 동적 메타태그

#### 관리자 사이트 (`/admin`)
- **대시보드** - 전체/오늘 가입자 수, 전체/오늘 게시글 수, 사이드바 처리 대기 배지(공간·물품 대여, 웰컴 키트, 신앙 질문, 신고)
- **회원 관리** - 검색·역할·교회 필터, 상태 변경(정지 시 refresh 토큰 전부 삭제), 역할 변경·삭제(최고관리자)
- **게시판 관리** - 카테고리 CRUD(비공개 포함), 게시글 상태 변경(ACTIVE/HIDDEN/DELETED)
- **행사·지역 섬김 관리** - 행사 CRUD, 상태 변경(DRAFT 포함), 참여자 목록
- **교회 관리** - 교회 정보 수정, 생성/삭제(최고관리자)
- **공간 관리** - 공간 CRUD, 차단 시간 관리, 대여 승인/거절, 관리자 메시지
- **물품 관리** - 물품 CRUD, 대여 승인/거절/반납 처리, 채팅
- **신앙 관리** - 전체 질문·기도제목 조회, 답변, "기도함" 표시 (목회자만)
- **웰컴 키트 관리** - 처리 완료 표시, 관리자 메시지, 삭제
- **신고 관리** - 상태별 목록, 해결/기각

### 미구현
- 이메일 인증 / 비밀번호 찾기·재설정 (메일 발송 기능 없음)
- 로그인 실패 횟수 기반 계정 잠금 (IP당 요청 수 제한만 있음, 05 참고)
- 실시간 알림/메시지 (WebSocket 등 없음, 주기적 조회)
